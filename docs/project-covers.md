# Capas dos projetos

As três capas são ilustrações conceituais geradas com a ferramenta integrada de imagens; não são capturas das aplicações. Os arquivos otimizados estão em `imgs/project-ping.webp`, `imgs/project-svg.webp` e `imgs/project-click.webp`.

## Prompts

- Painel Ping: Use case: stylized-concept. Landscape portfolio project cover, dark charcoal and warm orange sci-fi visual identity. Network monitoring concept: elegant central router node connected to luminous orange nodes, subtle latency pulse waveform, crisp dimensional black glass panels, restrained cinematic studio lighting. No words, no logos. Wide 3:2 composition, focus centered, readable at thumbnail scale.
- SVG Generator: Use case: stylized-concept. Landscape portfolio cover for a vector shape editor. Dark charcoal with warm orange accents. A luminous orange editable polygon with small square vertex handles and Bezier curves hovering over a fine technical grid, dimensional black glass workspace, tasteful sci-fi industrial design. No words, no logos. Wide 3:2 composition, focus centered, readable thumbnail.
- ClickLimit: Use case: stylized-concept. Landscape portfolio cover for ClickLimit, a mouse clicking utility. A sculptural matte charcoal computer mouse with bright orange illuminated button and a crisp oversized cursor pointer, concentric orange click pulse rings, subtle technical grid, tasteful sci-fi industrial studio lighting. No words, no logos. Wide 3:2 composition, center focus, readable thumbnail.

## Molduras

A moldura externa mantém o caminho enviado pelo autor, com viewBox ajustado aos limites do desenho. O SVG de cada capa reutiliza o segundo caminho como clipPath e contorno. O conteúdo textual continua em HTML, com links e botões acessíveis. A moldura acompanha a altura do conteúdo para acomodar diferentes larguras e tamanhos de texto.
