# Portfólio v1.0.0 — Cards SVG personalizados

- Molduras SVG criadas pelo autor, com contornos no vermelho de destaque do portfólio.
- Capas conceituais para Painel Ping, SVG Generator e ClickLimit.
- Botões circulares Código e Detalhes nos encaixes inferiores.
- Links, descrições e diálogos atualizados para os três projetos recentes.
- Layout conferido em 1440, 768 e 390 pixels; diálogos e fechamento com Escape verificados.
- Publicação automática no GitHub Pages a cada atualização da branch main.

## Executar

Extraia o ZIP e abra index.html em um navegador. Não exige instalação nem compilação.
